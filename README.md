# Slime Mechs!
Slime Mechs! is a stylized arena fighter set in New SlimeOpolis, a vibrant futuristic city where teenagers train to become the next generation of slime-mech pilots.

Stylized Arena Combat
Fight against slime-based enemies in contained arenas across the city.

Pilot a Slime Mech
Control a powerful mech designed to manipulate and counter slime-based threats.

| Action          | Key         |
| --------------- | ----------- |
| Move            | WASD        |
| Attack          | Left Click  |
| Special Ability | Right Click |
| Dash            | Shift       |
